# Albatros Progetti Web

Albatros ti aiuta a trasformare un'idea in un progetto web chiaro: obiettivo, pubblico, contenuti, piano delle pagine, bozza e verifica del prototipo locale. Le decisioni restano tue; Albatros ricorda il percorso scelto e i passi confermati.

Serve un account Albatros e accedi dal browser. La connessione legge lo stato del progetto e salva percorso, modalità di lavoro e passi del progetto o dell'apprendimento che confermi esplicitamente. In una chat ricevi un piano e il prossimo passo. I file locali e i prototipi possono essere modificati soltanto in un ambiente che lo consente e su tua richiesta. Il percorso termina con il tuo via libera al prototipo locale.

Supporto: mathias@albatrospartner.ch. Albatros Partner, Svizzera.

Pianifica il mio progetto web con Albatros.

Questo pacchetto contiene istruzioni Markdown locali e una connessione HTTPS ad Albatros. Non avvia programmi locali e non contiene hook. L’accesso usa OAuth nel browser. Gli otto strumenti leggono lo stato del progetto o salvano percorsi, modalità e passi scelti esplicitamente. Vengono trasmessi solo i campi inseriti per tali compiti; non è richiesta la cronologia della conversazione. L’ambito comprende P1–P10. Il pacchetto viene costruito dalla propria lista di file verificata.
