# Albatros Project Planning

Albatros helps turn your idea into a clear website project: purpose, audience, content, page plan, design and checks of your local prototype. You keep the decisions; Albatros remembers your chosen path and your confirmed progress.

You need an Albatros account and sign in in your browser. The connection reads your project state and saves your chosen path, working mode and explicitly confirmed project and learning steps. In a chat, you receive a plan and clear next steps. Local files and prototypes can only be edited in an environment that provides those capabilities and when you request that work. This workflow ends with approval of the local prototype.

Support: mathias@albatrospartner.ch. Made by Albatros Partner in Switzerland.

Plan my website project with Albatros.

This package contains a local Markdown workflow and an HTTPS connection to Albatros. It starts no local program and includes no hooks. Sign-in uses OAuth in the browser. Its eight tools read project state or save explicitly chosen paths, working modes, project steps and learning steps. Only the fields entered for those tasks are sent; the workflow does not request conversation histories. Its scope is P1 through P10. The package is built from its own reviewed file list.
