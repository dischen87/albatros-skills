# Albatros Planification

Albatros t'aide à transformer une idée en projet de site web clair : objectif, public, contenus, plan des pages, maquette et vérification du prototype local. Tu gardes les décisions ; Albatros retient ton parcours et tes étapes confirmées.

Un compte Albatros est nécessaire ; tu te connectes dans ton navigateur. La connexion lit l'état du projet et enregistre ton parcours, ton mode de travail et les étapes du projet ou de l'apprentissage que tu confirmes explicitement. Dans un chat, tu obtiens un plan et la prochaine étape. Les fichiers locaux et les prototypes ne peuvent être modifiés que dans un environnement qui le permet et sur ta demande. Le parcours se termine avec ta validation du prototype local.

Support : mathias@albatrospartner.ch. Albatros Partner, Suisse.

Planifie mon projet de site web avec Albatros.

Ce paquet contient une instruction Markdown locale et une connexion HTTPS à Albatros. Il ne lance aucun programme local et ne contient aucun hook. La connexion utilise OAuth dans le navigateur. Les huit outils lisent l’état du projet ou enregistrent les parcours, modes de travail et étapes explicitement choisis. Seuls les champs saisis pour ces tâches sont transmis ; aucun historique de conversation n’est demandé. Le périmètre couvre P1 à P10. Le paquet repose sur sa propre liste de fichiers vérifiée.
