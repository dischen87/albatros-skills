## De quoi il s'agit

Un colis n'est pas livré quand il est dans le camion, mais quand il est devant la porte. Alors on sonne. Un retour n'est réglé que quand la correction est visible sur ta page et que la personne le sait.

## Ce que tu apprends

- rassembler les retours en un seul endroit et les classer par page
- vérifier chaque signalement sur la vraie page, pas seulement dans le texte
- pourquoi « fini dans le code » ne veut pas encore dire réglé
- écrire une réponse courte et aimable, sans technique

## Comment t'y prendre

1. Rassembler avec ton IA tous les retours des derniers temps.
2. Les regrouper par page et les évaluer sur la vraie page.
3. Faire corriger un groupe après l'autre et le publier.
4. Vérifier toi-même si la correction est visible.
5. Prévenir la personne, et seulement ensuite fermer le ticket.

## Réussi quand

- `docs/feedback.md` avec les tickets, les réponses et un tour complet se trouve dans ton projet.
